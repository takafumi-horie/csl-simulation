# 原典互換プロファイルの10試行・500反復

レビュー指摘に対応した本番実装 `2af44df` で、INTERを10試行・各500反復実行した。
**全20最終状態の400配列項目が固定原典参照と完全一致し、独立再計算したARI160値も
一致した。** 今回の原典互換プロファイルへの移植は、この参照の長期実行結果まで再現した。
対象は現代環境に移した原典であり、当時のPython 2環境や論文ARI値そのものとの一致を
保証するものではない。

## 条件と検証の範囲

語彙13、各属性10カテゴリ、学習πのカテゴリ当たり集中度0.1（α/K）、γ=0.1。
初期化、θのDirichlet100標本平均と未補正θによる学習、μ100標本平均、空カテゴリの
一様配置、共有MT19937、通信・数値演算・前処理を原典プロファイルの仕様に揃えた。
初期Σは0.05Iで、GIW事前のスケール0.01Iと区別する。学習πは1標本である。

各試行のseedは0〜9、初期化から最後まで同じローカルRandomStateをA/Bで共有し、
BLAS/OpenMPを各プロセス1スレッドに固定した。10試行を並列実行しているが、
主体間の半ターンは各試行内で逐次実行する。入力・数値環境・ハッシュはmanifestと
各試行の出自記録に保存した。以前の4機能版はSeedSequenceから試行とA/Bへspawnする
別の系列であり、同じ試行番号でも対応する乱数軌道ではない。

原典参照は以前に選択・使用した試行を含む既存の10試行で、新しい盲検確認とは呼ばない。
今回は全試行の最終反復を評価し、結果による条件変更、最良試行・反復の選別はしていない。
SINGLE原典との一致やSINGLE論文値の再現は、このINTERの結果から認定しない。

400項目の比較では、θ・z・π・μ・Σなどの数値配列のdtype・shape・bytesを照合する。
語はnativeのflat表現を行列へ戻し、属性列と語彙はmetadataから参照の配列表現へ
対応付ける。保存形式の違いを正規化した状態内容の一致であり、異なるNPZ/JSON形式の
ファイル全体のbyte一致を意味しない。全500反復の中間状態を原典と照合したわけでもない。

本番historyの500行、共有RNGの1,001境界、最終CSVのzとcheckpoint、最終ARIを検証した。
さらに5,000個の反復ディレクトリと210,000個のCSVファイルの存在を確認した。
この存在確認は、全中間Gaussian・θの数値や全反復のARIを再計算したという意味ではない。
RNG記録は10試行合計で未圧縮68,407,939 bytes、gzip 36,425,512 bytesとなった。
数値・境界を失わず保存容量を約53.2%に抑えた。

Aの動作先頭3列にはBの値域を使う原典の前処理も、このプロファイルに限り含めた。
前処理は現行方式の方が合理的と考えられるが、論文実装とは若干異なるという著者の
見解を維持する。原典互換の前処理を一般的な推奨方法としているわけではない。
