# 本番ブランチでのINTER ARI再実行

## 固定する条件

対象は `feature/original-heuristics` の `12ef90f` にある
`examples/inter_original_heuristics.yaml`。学習コードや前処理を変更せず、
500反復・10試行を新規実行する。設定例から変更するのは試行数、run名、
入力・出力の絶対パスのみ。SINGLEの設定・論文実験は今回の対象に含めない。

- 語彙13、各属性10カテゴリ、カテゴリ当たり集中度0.1、gamma 0.1。
- θはDirichlet 100標本平均、学習z/Fは未補正θ。
- 占有カテゴリのμは100標本平均、空カテゴリのμは原典の一様生成。
- 初期化・前処理・語生成・MH受理・通信順序・保存処理は本番実装のまま。
- seed 0の `SeedSequence.spawn(10)` の試行番号0〜9を全て使い、
  各試行から `spawn(2)` でA/BのGeneratorを生成する。
- 結果に応じた条件変更、試行の選別、最良反復の選択、早期終了は行わない。

並列実行は本番runnerの試行関数を試行単位で呼ぶ。試行ごとのseedと
学習・保存処理は、通常の `learn()` の10試行設定と同じにする。
調査用adapterは学習に使用しない。

## 評価

500反復後のcheckpointから `adjusted_rand_score` を再計算する。
主表は動作30文書、位置・形状・色は注意対象30物体についてA/Bを別々に示す。
補表では位置・形状・色の全55物体も評価する。
10試行の平均と標本標準偏差（ddof=1）を示し、論文値との差を併記する。
本番の解析JSONと再計算値の一致、試行完了と履歴500行、状態の形状・有限性を
確認する。入力・実装・実行環境・最終状態のハッシュを記録する。

比較値は[論文Table 3](https://arxiv.org/html/2306.15837v1#S3.T3)の
提案手法のARI（動作0.309、位置0.794、形状0.286、色0.949）に固定する。
取得した値と出典は [paper_reference.json](paper_reference.json) に保存する。
論文表の標準偏差やA/B集約方法が確定していないため、統計的な同等性や
論文実行の完全再現を判定するものではない。今回の正解データは、ユーザー確認に
より論文実験で使われたものと同一であり、評価対象集合・集約方法の論点と区別する。

これは選定済み構成の本番実装での再実行である。試行番号0〜9は過去の探索で
一部使われているため、探索から独立した盲検確認とは呼ばない。
過去のB2確認10試行（番号10〜19）と今回の結果を同一集合として扱わない。
全試行の軽量結果・再実行スクリプト・条件をブランチへ保存し、大量の本番出力は
gitignore対象の `outputs/` に保持する。
