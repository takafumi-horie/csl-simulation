2026年11月17日JST。ユーザー指名の独立レビュワは `54a09d7`（基準 `455b499`）を
ブロッカーなしで承認した。以下は指摘への実装者側の追加対応である。

## レビュワによる確認（提供されたレビューに基づく）

- 全204テストと `git diff --check` が通過。通常の設定例2ファイルも未変更。
- 原典3ソースの読取り・初期化・学習全体を本番実装と照合。
- seed 7・0で各3反復19境界、seed 3・5で各30反復181境界を再実行し、
  原典とのbyte一致を確認。本番runnerの保存状態・RNGも照合。

- Ruffはレビュワ環境に未導入のため未確認。実装者側では版を明記して実行する。

レビュー再実行の全成果物を受領したわけではないため、上記を実装者が新たに
独立再検証した結果とは扱わない。

## 6件の指摘と対応

1. **原典や実データがなくても走る独立参照テスト**を追加した。
   合成の複数物体・非ゼロ注意対象を含むfixture上で、原典の乱数手順と数式を
   RandomStateで手書きした参照と共同初期化・1反復を照合する。
   通常モデルから継承するπ事後・θ事後・注意対象の処理も参照側では独立に計算する。
2. 後方互換性の旧版対照は**モデル層の状態・RNG・状態metadata**の比較であると明記。
   `learn()` / CLIの全出力の旧版対照ではなく、loaderの処理順等は結合テストと
   コードレビューの範囲である。`resolved_config.yaml` の新キー追加も明記した。
3. RNG境界は `rng_boundaries.jsonl.gz` に可逆圧縮して保存する。
   情報量・保存境界は同じで、展開後の値の往復と乱数非干渉をテストする。
   500反復のINTERは1,001レコードになる。実測容量は長期比較の出力に記録する。
4. 出自記録に6種のスレッド環境変数（未設定はnull）と実際のthreadpool情報を追加。
   実装は環境を強制変更せず、再現条件にスレッド数を含むとREADMEに明記する。
   今回の照合と長期比較はBLAS/OpenMP各1スレッドで実行する。
5. 手順のPython実体・site-packagesをプレースホルダへ変更し、特定マシンの
   `/tmp` 出力を必要とする説明を除いた。過去の結果JSON内の実行時パスは出自として維持する。
6. カーネルの文脈付きエラーを `OriginalExecutionError` として識別し、runnerで
   同じ文脈を付け直さずそのまま送出する。文脈のないエラーだけrunnerで補う。
